# Cyber Threat Intelligence Dashboard

Cyber Threat Intelligence Dashboard is a cybersecurity web application built using Flask, SQLite, HTML, CSS, and JavaScript. The project is designed to help users learn about cyber threats, phishing attacks, password security, and basic threat intelligence concepts through an interactive dashboard.

## Features

- Threat intelligence dashboard
- Add and manage cyber threats
- Search threat reports
- Password strength checker
- Phishing awareness section
- Cybersecurity safety tips
- Responsive web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
